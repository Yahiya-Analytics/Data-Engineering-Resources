Learning Roadmap — Beginner to Production

Phase 1 · Months 1–3
Foundations
  • Python basics: functions, classes, file I/O, virtual environments
  • SQL: SELECT, JOINs, CTEs, window functions, query optimization
  • Linux/Bash: shell scripting, SSH, package managers
  • Git & GitHub: version control, branching, pull requests
  • Relational databases: PostgreSQL fundamentals, schema design
  • Resources: roadmap.sh/data-engineer, Dataquest DE Roadmap
Phase 2 · Months 3–5
Core Data Engineering
  • Docker: containerize pipelines, Docker Compose, networking
  • Workflow orchestration: Apache Airflow or Kestra
  • Data ingestion: Airbyte, dlt, or Meltano for EL pipelines
  • Cloud basics: GCP / AWS / Azure — storage, compute, IAM
  • Data warehousing: BigQuery or Snowflake, partitioning, clustering
  • Resources: DE Zoomcamp (Modules 1–3), MotherDuck Roadmap
Phase 3 · Months 5–8
Transformation & Analytics Engineering
  • dbt: models, tests, documentation, macros, seeds, snapshots
  • Data modeling: star schema, Kimball, data vault, OBT
  • Infrastructure as Code: Terraform for cloud resources
  • Data quality: Great Expectations or dbt tests at scale
  • Resources: DE Zoomcamp (Modules 4–5), dbt courses
Phase 4 · Months 8–12
Batch & Streaming at Scale
  • Apache Spark: DataFrames, Spark SQL, GroupBy internals, joins
  • Stream processing: Apache Kafka, Kafka Streams, KSQL
  • Schema management: Apache Avro, Schema Registry
  • Open table formats: Apache Iceberg, Delta Lake, or Apache Hudi
  • Resources: DE Zoomcamp (Modules 6–7), Spark Playground
Phase 5 · Ongoing
Production Skills & AI Era
  • CI/CD for data pipelines: GitHub Actions, testing, deployment
  • Monitoring & observability: data lineage, alerting, SLAs
  • AI-era DE: embedding generation at scale, vector databases, LLM pipelines
  • Data contracts and governance: privacy compliance, schema contracts
  • Portfolio projects: end-to-end pipelines on real datasets
  • Resources: DataExpert.io newsletter, "Fundamentals of Data Engineering" book
