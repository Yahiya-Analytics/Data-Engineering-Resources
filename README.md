## ✨ Features

### Web Version (GitHub Pages)
- 🌙 **Dark theme** optimized for long reading sessions
- 🔍 **Real-time search** across all 60+ resources
- 🏷️ **Category filtering** — filter by cost (Free / Paid), type, or topic
- 📱 **Mobile responsive** — works great on phones and tablets
- 🗺️ **Interactive roadmap** — visual 5-phase learning path
- 🔗 **Clickable links** — every resource opens in a new tab

### Spreadsheet Version
- 🎨 **Color-coded categories** — instantly spot GitHub repos, courses, blogs, etc.
- ✅ **Dropdown validation** — consistent tagging for category and cost
- 📝 **Personal notes column** — track your progress, ratings, and thoughts
- ❄️ **Frozen headers** — scroll through 40+ rows without losing context
- 📤 **Easy import** — upload to Google Sheets, Notion, or Airtable

## 🗺 Learning Roadmap

| Phase | Duration | Focus |
|-------|----------|-------|
| **Phase 1** | Months 1–3 | Python, SQL, Linux/Bash, Git, PostgreSQL |
| **Phase 2** | Months 3–5 | Docker, Airflow/Kestra, Cloud basics, Warehousing |
| **Phase 3** | Months 5–8 | dbt, Data modeling, Terraform, Data quality |
| **Phase 4** | Months 8–12 | Spark, Kafka, Schema registry, Open table formats |
| **Phase 5** | Ongoing | CI/CD, Monitoring, AI-era DE, Data contracts |

> 💡 **Pro tip:** Start with [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) (free, 9 weeks) alongside Phase 1–2 skills.

## 🤝 Contributing

This hub is **community-curated**. Found a broken link? Know a great resource we missed? Want to add your own project?

1. Fork this repository
2. Add your resource to `index.html` (web) or the spreadsheet
3. Submit a Pull Request with a brief description

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.

### Resource Criteria
- ✅ Relevant to data engineering (not generic data science)
- ✅ High quality — well-maintained, accurate, useful
- ✅ Accessible — free resources strongly preferred; paid ones must be exceptional
- ✅ Diverse — covers different learning styles (video, text, interactive, audio)
